system, a spreadsheet everyone trusts. Enterprise platforms, AI voice and chat agents, and the
integrations between them. I build my own AI agents to do it faster, and I verify against the live
system before anyone else has to.

**What the site covers**

- **Enterprise platforms** — a company-wide CRM built natively on Priority ERP, live in production
- **AI voice agents** — product strategy, a 14-stage PRD, and the telephony architecture behind it
- **Conversational bots** — button-driven WhatsApp bots, and the tooling that turns an approved
  spec straight into the platform's import format
- **AI agent tooling** — sixteen custom agent skills that review specs, verify fixes against source,
  and QA a product against its real backend
- **Judgement** — three cases where measuring the live system changed the plan before anything got built

## About this repository

One file. `index.html` is the entire site — no build step, no framework, no dependencies to
install. Open it locally or drop it on any static host.

```
index.html      the whole site: markup, styles and scripts
README.md       this file
```

**How it's built**

| | |
|---|---|
| Markup & styles | Hand-written HTML and CSS, no framework |
| Type | Geist and Geist Mono, via Google Fonts |
| Starfield | A `<canvas>` generated at runtime — no image assets |
| Diagrams | Inline SVG, hand-authored |
| Motion | Honours `prefers-reduced-motion` |
| Hosting | GitHub Pages, from `main` |

**A note on the illustrations.** Every visual on the site is drawn for the page rather than
screenshotted. They show the structure of each system and contain no customer, order, supplier or pricing data.
